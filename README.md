# 나만의 프롬프트 관리 프로그램

파편화된 프롬프트(텍스트 생성, 이미지 생성, 페르소나 설계 등)를
한 곳에서 체계적으로 관리할 수 있는 파이썬 콘솔 프로그램입니다.

터미널에서 메뉴 번호를 입력하여 프롬프트를 추가, 조회, 검색, 즐겨찾기 관리할 수 있습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 이 저장소를 클론하거나 다운로드합니다.
3. 프로젝트 폴더로 이동한 뒤 실행합니다.
4. 메뉴에 표시되는 번호를 입력하여 원하는 기능을 사용합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력하여 새 프롬프트를 등록합니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호, 카테고리, 즐겨찾기 여부와 함께 보여줍니다. |
| 3 | 카테고리별 조회 | 선택한 카테고리에 해당하는 프롬프트만 조회합니다. |
| 4 | 프롬프트 검색 | 키워드를 입력하여 제목/내용에 포함된 프롬프트를 찾습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하여 해당 프롬프트의 전체 내용을 확인합니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력하여 즐겨찾기를 추가/해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 봅니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 참고 사항

- 프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 프로그램을 종료하면 초기화됩니다.
- 프로그램 시작 시 기본 프롬프트 3개가 미리 등록되어 있습니다.
